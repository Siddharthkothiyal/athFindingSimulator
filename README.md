# 🧭 PathFindingSimulator

A Java-based simulator for visualizing **pathfinding algorithms** like BFS, DFS, Dijkstra, and A*.  
Built for learning and experimentation with graph and grid traversal techniques.

## ✨ Features

- 🔹 Implementation of popular pathfinding algorithms:
  - Breadth-First Search (BFS)  
  - Depth-First Search (DFS)  
  - Dijkstra’s Algorithm  
  - A* Search  
- 🔹 Visualizes traversal step-by-step  
- 🔹 Adjustable grid, start, and goal nodes  
- 🔹 Interactive simulation controls (start, pause, reset)  
- 🔹 Clean Java OOP design for easy extension
